# Synthetic demo data for the Deep Learning + NLP add-on

These three CSVs are generated by `python -m scripts.generate_demo_data` with seed `20261028`.
They contain no real customers, personal information, or real customer-support conversations.

| File | Rows (seeded build) | Purpose |
|---|---:|---|
| `telco_customer_churn_demo.csv` | 1,200 | Synthetic structured customer rows using the same column names as the existing Telco churn pipeline. The synthetic `Churn` column is generated from a stochastic rule, not real outcomes. |
| `customer_support_text_demo.csv` | 1,595 | Synthetic support tickets linked to `customerID`, with `ticket_date`, `ticket_text`, and generated `true_sentiment` labels. All dates precede the simulated churn snapshot date of 2026-10-01. |
| `customer_text_features_demo.csv` | 625 | Customer-level, precomputed synthetic sentiment aggregates for testing the optional hybrid-model join without needing to download the Transformer first. These are **not** real model predictions. |

## Important limitations

- Use these files to verify installation, exercise the code paths, and learn the workflow only.
- Do not report performance numbers from these files as evidence of real-world churn prediction quality.
- `true_sentiment` is a generated label that reflects how each demo sentence was constructed. It is not a human annotation and cannot validate sentiment performance on real support messages.
- The precomputed aggregate CSV is deliberately synthetic so the optional hybrid model can be smoke-tested offline. For a real NLP experiment, run `scripts/analyze_support_text.py` against properly licensed or consented text data, inspect the output, and evaluate on manually labelled domain-relevant messages.
- The ticket data is correlated with an unobserved simulated dissatisfaction signal that also affects generated churn. This helps demonstrate a plausible join, but does not reproduce the complexity or noise of real customer behavior.

For a fresh deterministic dataset, from the repository root run:

```powershell
python -m scripts.generate_demo_data
```
